The input is a table of summary acoustic features, one entry per logger (site), from nocturnal vibration recordings of buried water mains (4,096 Hz sampling, 0 to 2,048 Hz band). For each site, estimate the probability that a leak is present near the logger. Return ONLY a JSON array (no markdown fence, no commentary), one object per site, with exactly these keys: site, leak_probability (number 0 to 1), verdict (LEAK or NO LEAK), reason (max 30 words).
